TypeScript · ESM + CJS · zero transitive dependencies

Read, write and edit Excel.
Without breaking your file.

When you open an .xlsx, change a value and save, most libraries rebuild the whole package and silently drop formatting, data validations, conditional formatting or images. sheet-lite patches only what changed and carries everything else over untouched.

Quickstart API reference
  • ~149 ms to read a 5000 × 8 sheet
  • ~23.9 kB gzip, including deps
  • 0 transitive dependencies
  • fflate is the only dependency

The public promise is “opens without repair.” Untouched parts of the file are preserved; when nothing changes, the original bytes are returned verbatim.

Why sheet-lite

The most-downloaded library in this space can destroy your data when you read and re-write an existing workbook. sheet-lite is built around a single principle: patch-only + copy-verbatim.

The preservation promise

  • Only the cells that actually changed are rewritten.
  • Data validations, conditional formatting, merges and images stay intact.
  • Styles and number formats are carried over per cell.
  • A no-op edit returns the original bytes exactly.
  • Security by design: path-traversal, entry-count, size and compression-ratio limits.

Lightweight by construction

  • Only fflate — the ZIP + DEFLATE layer, ~8 kB, 0 transitive deps.
  • Runs on raw bytes: Node, browsers and edge runtimes.
  • TypeScript-first, shipped as both ESM and CJS.
  • Filesystem access is lazy (node:fs/promises), so the core stays runtime-agnostic.

Install

One package. One dependency. Nothing else is pulled in transitively.

bash 
npm install sheet-lite

Or with your package manager of choice:

bash 
pnpm add sheet-lite
yarn add sheet-lite

Requires Node ≥ 18. In browsers and edge runtimes, import the ESM build and work with raw bytes — no filesystem access needed.

Quickstart

Read a file, patch a cell and add a row — everything else stays byte-identical.

ts 
import { Workbook } from 'sheet-lite';

const wb = await Workbook.readFile('./report.xlsx');
const ws = wb.getWorksheet('Sheet1')!;

// Read a value and its type
console.log(ws.getCell('A1').value, ws.getCell('A1').type);

// Edit — only the changed cells are rewritten
ws.getCell('B2').value = 1234.56;
ws.getCell('B3').value = new Date();
ws.getCell('B4').value = { formula: 'SUM(B2:B3)', result: 1234.56 };
ws.addRow(['North', 128]);

await wb.writeFile('./report-edited.xlsx');
// data validations, conditional formatting, merges and other parts stay intact

Workbook.read() is synchronous and works on raw bytes: Workbook.read(bytes) where bytes is a Uint8Array, ArrayBuffer or any ArrayBufferView. readFile() and writeFile() are the only filesystem-bound helpers and are Node-only.

API reference

The public surface is small and synchronous where it can be. Everything below is exported from the package root.

ts 
import {
  Workbook,
  Worksheet,
  Row,
  Cell,
  ValueType,
  typeOf,
  SheetLiteError,
  ZipSecurityError,
} from 'sheet-lite';

class Workbook

The entry point. Loads an OPC package and writes it back losslessly.

Member Signature Description
read static read(input: Uint8Array | ArrayBuffer | ArrayBufferView): Workbook Read a workbook from raw bytes (Node, browser, edge). Synchronous.
readFile static readFile(path: string): Promise<Workbook> Read from a filesystem path. Node only.
worksheets get worksheets: Worksheet[] All sheets, in package order.
sheetNames get sheetNames: string[] Sheet names in package order. Also available as getSheetNames().
getWorksheet getWorksheet(nameOrId: string | number): Worksheet | undefined Find a sheet by name or numeric id.
toBuffer toBuffer(): Uint8Array Serialize. If nothing changed, the original bytes are returned verbatim.
writeFile writeFile(path: string): Promise<void> Write to a filesystem path. Node only.
metadata get metadata: PackageMeta Read-only package metadata (date system, shared strings, styles).

class Worksheet

A single sheet. Reading values and patching cells/rows are supported; everything else in the sheet XML is preserved.

Member Signature Description

id readonly id: number Numeric sheet id from the package.
rowCount get rowCount: number Highest populated row, including pending edits.
columnCount get columnCount: number Highest populated column, including pending edits.

addRow addRow(values: CellValue[]): Row Append a row starting at column A. Returns the created Row.

Row

Member Signature Description

class Cell

A reference to a single cell. value is both readable and writable; writing registers a surgical patch.

Member Signature Description
address get address: string A1-style address, e.g. "B2".
row get row: number 1-based row number.
col get col: number 1-based column number.
value get/set value: CellValue Current value. Assigning marks the cell as changed.
type get type: ValueTypeName 'Null' | 'Number' | 'String' | 'Date' | 'Boolean' | 'Formula' | 'Error'.
model get model: { address; type; value } Convenience snapshot of the cell.

union CellValue

Values are modelled to align with ExcelJS's CellValue, so migration is straightforward:

ts 
type CellValue =
  | null
  | number
  | string
  | boolean
  | Date
  | { error: string }
  | { formula: string; result?: CellValue };

Cell.type and the exported typeOf() report the kind as a ValueTypeName. The ValueType map gives the numeric constants:

ValueType Value Example
Null0null
Number11234.56
String2'North'
Date3new Date()
Boolean4true
Formula5{ formula: 'A1+B1' }
Error6{ error: '#DIV/0!' }

Values are read from strings, numbers, booleans, dates (both the 1900 and 1904 systems), formulas (with their cached result), and inline/shared strings.

class Errors

Type code Thrown when
SheetLiteError varies, e.g. 'NOT_XLSX' The input isn't a valid XLSX package (every error carries a stable machine-readable code).
ZipSecurityError 'ZIP_SECURITY' The archive violates a safety limit: path traversal, too many entries, oversized parts or a suspicious compression ratio.
ts 
import { Workbook, SheetLiteError, ZipSecurityError } from 'sheet-lite';

try {
  const wb = await Workbook.readFile('./maybe-not-excel.xlsx');
} catch (error) {
  if (error instanceof ZipSecurityError) {
    console.error('Rejected unsafe archive:', error.code);
  } else if (error instanceof SheetLiteError) {
    console.error('Invalid package:', error.code);
  } else {
    throw error;
  }
}

Examples

Copy-pasteable snippets. Every write below preserves the rest of the file.

1 · Read values

Read individual cells by A1 reference or by row/column, or walk every populated row with eachRow.

ts 
import { Workbook } from 'sheet-lite';

const wb = await Workbook.readFile('./report.xlsx');
const ws = wb.getWorksheet('Sheet1')!;

// Random access
const a1 = ws.getCell('A1');
console.log(a1.value); // e.g. 'Region'
console.log(a1.type);  // 'String'

// Same cell, by 1-based coordinates
const b2 = ws.getCell(2, 2);
console.log(b2.address, b2.value); // 'B2', 128

// Iterate populated rows in ascending order
ws.eachRow((row, rowNumber) => {
  const values = row.cells.map((cell) => cell.value);
  console.log(rowNumber, values);
});

2 · Edit a cell and preserve formatting

Assigning to value registers a patch for that cell only. Its original style index — fonts, fills, borders and number format — is retained, and every other byte of the sheet XML is carried over as-is.

ts 
import { Workbook } from 'sheet-lite';

const wb = await Workbook.readFile('./report.xlsx');
const ws = wb.getWorksheet('Sheet1')!;

// Patch a single styled cell — the surrounding file stays intact
ws.getCell('B2').value = 1234.56;

await wb.writeFile('./report-edited.xlsx');
// data validations, conditional formatting, merges and images survive

If you change nothing at all, toBuffer() returns the original bytes verbatim — a true no-op round-trip.

3 · Add rows

addRow appends below the last populated row, starting at column A. It accepts the same CellValue union, and returns the created row.

ts 
import { Workbook } from 'sheet-lite';

const wb = await Workbook.readFile('./report.xlsx');
const ws = wb.getWorksheet('Sheet1')!;

ws.addRow(['North', 128, true]);
ws.addRow(['South', 94, false]);

// addRow returns the new Row
const row = ws.addRow(['West', 61, true]);
console.log(row.number);          // e.g. 42
console.log(row.getCell(1).value); // 'West'

await wb.writeFile('./report-edited.xlsx');

4 · Working with dates

Date cells are decoded into native Date objects, honouring both the 1900 and 1904 date systems. Writing a Date stores the Excel serial number; when you patch a cell that already carries a date number format, that format is preserved so Excel still renders a date.

ts 
import { Workbook } from 'sheet-lite';

const wb = await Workbook.readFile('./report.xlsx');
const ws = wb.getWorksheet('Sheet1')!;

// Reading: date-formatted cells come back as Date instances
const when = ws.getCell('B3').value;
if (when instanceof Date) {
  console.log(when.toISOString());
}

// Writing: a Date becomes its Excel serial number
ws.getCell('B3').value = new Date('2026-01-15T00:00:00Z');

await wb.writeFile('./report-edited.xlsx');

Need manual control? The helpers serialToDate() and dateToSerial() are exported for converting between Excel serial numbers and Date values.

5 · Formulas

A formula cell is read as { formula, result }, where result is Excel's cached value. To write one, provide the formula text and, optionally, the cached result.

ts 
import { Workbook } from 'sheet-lite';

const wb = await Workbook.readFile('./report.xlsx');
const ws = wb.getWorksheet('Sheet1')!;

// Reading a formula exposes its text and cached result
const total = ws.getCell('B5').value;
// { formula: 'SUM(B2:B4)', result: 1234.56 }

// Writing a formula (result is optional)
ws.getCell('B5').value = { formula: 'SUM(B2:B4)', result: 1234.56 };

await wb.writeFile('./report-edited.xlsx');

sheet-lite does not evaluate formulas. The result is the cached value Excel stored — supply it when you want readers that don't recalculate to show a value.
